## Stack
- **Framework:** React  *(one of: react · angular · vue · svelte · web-components · swiftui · compose)*
- **Language:** TypeScript (strict)

## Tokens
- **Source of truth:** Figma variables (the tokens file — `figma.files.tokens`)
- **Build tool:** **Style Dictionary**
- **Platforms built:** `css`, `js`  *(from `tokens.platforms` in config)*
- **Output:** `build/tokens/<platform>/…` (e.g. `tokens.css`) — components consume these, never raw values
- **Themes:** each Figma **mode** → a **theme** in the output (light/dark, brand A/B). Semantic token
  names stay the same across themes; only values change. Components switch themes, not values.

## Which tool for what
| Job | Tool |
|---|---|
| Component code | React + TypeScript |
| Styling | tokens generated by **Style Dictionary** (e.g. CSS variables) — never a raw value |
| Build tokens | `npm run tokens:build` (Style Dictionary) |
| States + preview | Storybook |
| Unit tests | vitest |
| Docs | Astro Starlight |
| Deploy | GitHub Pages via Actions *(only if `deploy.enabled`)* |
| Dashboard · Tasks | Airtable · Asana |

## Rule
No component is built until tokens are configured and built for this platform.
If they aren't, the PM assigns 🎨 token-audit to set them up first.
